📞 Number Directory Bot

بوت Telegram لدليل الأرقام، مبني باستخدام Python وSQLite.

✨ المميزات

- 🔎 البحث عن رقم
- 📱 عرض معلومات أساسية عن الرقم
- 🌍 محاولة تحديد الدولة من رمز الاتصال
- ➕ إضافة الرقم بواسطة صاحبه
- 🗑 حذف الرقم الذي قام المستخدم بتسجيله
- 📊 إحصائيات المستخدمين والأرقام وعمليات البحث
- 💾 قاعدة بيانات SQLite
- 🔐 حماية توكن Telegram من الرفع إلى GitHub
- ☁️ جاهز للنشر على Render

📁 هيكل المشروع

number-directory-bot/
├── main.py
├── config.py
├── database.py
├── requirements.txt
├── .env.example
├── .gitignore
└── README.md

🛠️ التشغيل محليًا

ثبت المتطلبات:

pip install -r requirements.txt

أنشئ ملف ".env":

TELEGRAM_BOT_TOKEN=ضع_توكن_البوت_هنا
DB_NAME=numbers.db

ثم شغل:

python main.py

🤖 أوامر البوت

/start
/help

ومن القائمة الرئيسية يمكن استخدام:

- 🔎 بحث عن رقم
- 📱 معلومات الرقم
- ➕ إضافة رقمي
- 🗑 حذف رقمي
- 📊 الإحصائيات

🔐 الأمان

لا تضع توكن Telegram الحقيقي داخل ملفات المشروع التي سترفعها إلى GitHub.

استخدم متغير البيئة:

TELEGRAM_BOT_TOKEN=YOUR_TOKEN

ملف ".env" مستثنى من Git بواسطة ".gitignore".

⚠️ الخصوصية

هذا المشروع مصمم ليعمل كدليل أرقام يعتمد على البيانات التي يضيفها أصحاب الأرقام بأنفسهم.

لا يعتمد المشروع على قواعد بيانات مسروقة أو بيانات شخصية خاصة يتم الحصول عليها دون تصريح.

🚀 النشر

المشروع مصمم ليتم رفعه إلى GitHub ثم تشغيله على خدمة استضافة مثل Render.
